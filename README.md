# Retail Sales Analytics Using SQL

## Project Overview

This project analyzes retail sales data using PostgreSQL to understand sales performance, customer purchasing behavior, product category performance, and transaction trends.

## Tools Used

* PostgreSQL
* pgAdmin 4
* SQL

## Dataset Columns

* transaction_id
* sales_data
* sales_time
* customer_id
* gender
* age_category
* quantity
* price_per_unit
* cogs
* total_sales

## Business Questions

1. How many total transactions are present in the dataset?
2. How many unique customers are there?
3. Are there any missing values in important columns?
4. What is the total revenue generated?
5. Which product category generates the highest sales?
6. Which product category has the highest number of transactions?
7. What is the average price per unit for a product category?
8. Which transactions have total sales greater than 100?
9. How many transactions are recorded for each gender and product category?
10. What is the average sales amount for each month and year?
11. Who are the top 5 customers based on total sales?
12. How many unique customers purchase in each category?
13. During which time period are the most orders placed?

## SQL Concepts Used

* SELECT and WHERE
* COUNT and DISTINCT
* SUM and AVG
* GROUP BY and ORDER BY
* NULL value checking
* Date and time functions
* CASE WHEN
* Common Table Expressions (CTEs)
* LIMIT

## Project Objective

The objective is to use SQL queries to analyze retail transactions and generate insights that can support business decisions.
